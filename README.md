# KTH Sepsis PWA

Progressive Web App launcher สำหรับระบบ SMART SEPSIS DIGITAL SCREENING โรงพยาบาลขุนตาล

- ชื่อแอป: KTH Sepsis
- รองรับการติดตั้งบน iOS, Android, Windows, macOS และ ChromeOS
- ตัวแอปเปิด Google Apps Script Web App เดิมภายในหน้าต่างแบบ standalone
- ไม่เก็บข้อมูลผู้ป่วยไว้ใน GitHub หรือ Service Worker cache

เปิดใช้งานผ่าน GitHub Pages แล้วเลือก Add to Home Screen หรือ Install app จากเบราว์เซอร์
